# UX 2.0 screen and journey inventory

Companion to [M1 findings](UX_2_M1_AUDIT.md). Audited October 29, 2026, against both working trees.

## Reading the inventory

Routes are React Navigation keys, not URLs. Source files are `src/screens/<name>Screen.tsx` unless specified. `Main` hosts `src/navigation/MainTabs.tsx`; authentication gates render outside NavigationContainer.

Counts are source-traced minimums **from the entry point named in each row**, not observed measurements. `+edit` means field input beyond the listed buttons; `+OS` means permission, camera/library, share/email/browser interactions. `S` counts app screens including the entry surface; `O` counts an additional sheet/modal/alert when material. Alerts after a successful save are excluded unless listed. Choosing a nondefault option increases the count.

Scroll exposure is qualitative: **short** = compact state, **medium** = several sections, **long** = full forms/repeated content, **variable** = list/data dependent. Exact distance is **unmeasured for every row**. These categories are source estimates, not a viewport measurement.

Issue notation in the second table: **U** unnecessary controls/repeated copy; **H** hierarchy/layout; **S** state/recovery; **A** accessibility; **N** navigation. `native` means default stack Back exists, not device-verified reliability. A named guard is source-confirmed; no guard means no removal guard found for that draft.
